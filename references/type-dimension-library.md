# Book Type → Dimension Library

Open table, not a closed taxonomy. Add rows when the unknown-type fallback produces a validated new type.

## The five universal questions (every book)

1. What question is this book answering?
2. Why is this author qualified to write it?
3. What are the 3–5 most important ideas, explained in plain language?
4. What is the one sentence the reader should walk away with?
5. Who is it for, and how should they read it?

These are the shared foundation — they are NOT five fixed columns on every infographic. The layout decides how they surface.

## Type table

| Type | Extra dimensions (pick 2–4, never all) |
|---|---|
| History | timeline (5–7 beats), periodization, turning points, multiple perspectives, one-line historical pattern |
| Biography | life stages, decisive choices, character drivers, era context, legacy & controversy |
| Ideas / Philosophy | core theses, concept relationships, argument chain, clash with opposing views, what's debatable |
| Social-science theory | base assumptions, core model, predictions, reality check, explanatory limits |
| Natural science | core mechanism, key evidence, old belief overturned, applications, open questions |
| Thinking methods | toolbox (name + how to use + example), counter-intuitive points, when it works / doesn't |
| Business / Management | key numbers, action framework, org rollout, cases, failure modes & pitfalls |
| Psychology / Growth | core model, common misconceptions, practical steps, strength of evidence, boundaries |
| Technical practice | core principle, mental model, option comparison, operating procedure, common gotchas |
| Literary fiction | story arc, character map, character transformation, themes & motifs, narrative structure — experimental: fiction infographics follow different logic; deepen per project |

## Mixed types

- One primary type, at most two secondary types.
- Combine dimensions from each into a single coherent brief. Never staple two templates together.

## Unknown-type fallback

1. Answer the five universal questions.
2. Infer 2–4 bespoke dimensions from the table of contents, narrative structure, evidence style, or argument structure.
3. Write down why these dimensions were chosen.
4. After shipping, decide whether the new type is worth adding to this table.
5. Never force-fit an existing template just to hit a category.
