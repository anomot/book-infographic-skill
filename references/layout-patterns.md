# Layout Pattern Library

Choose by information relationship, not by book type. One primary structure per infographic; a second may support it, but there must be a clear lead.

| Pattern | Fits information that is… | Typical use |
|---|---|---|
| Timeline | chronological, a causal chain over time | histories, biographies, tech evolution |
| Toolbox | a set of independent, usable tools | thinking methods, practical guides |
| Concept map | radial relationships around one idea | philosophy, worldview books, theory-building |
| Dashboard | a few big numbers + a framework | business, economics with hard data |
| Character arc | transformation over a journey | biography, fiction |
| Comparison matrix | A-vs-B, options, debates | route disputes, opposing schools, buyer's guides |
| Causal mechanism | input → mechanism → output | science explainers, "how it works" books |

## Visual identity per book

- One visual motif carried through the whole piece (a recurring shape, line, or symbol tied to the book's subject).
- Palette: at most three main colors plus a paper tone.
- Typographic scale: one amplified takeaway line at ~2x size; clear hierarchy below it; generous whitespace (aim ≥ 30%).
- Key numbers become visual anchors — big, isolated, impossible to miss.

## Anti-AI styling rules

- Never all-centered, all-cards, or evenly chunked grids.
- Use asymmetry: split columns, scale contrast, whitespace, and visual anchors to create editorial rhythm.
- At most one decorative illustration; every other graphic must carry information (timeline, table, matrix, flow, map).
- Column headers in natural spoken language (e.g. "这本书在回答什么", "他凭什么写"), never "核心概念" / "作者简介" boilerplate.
- Same batch, different skeletons: two books must never share the same structural backbone.
